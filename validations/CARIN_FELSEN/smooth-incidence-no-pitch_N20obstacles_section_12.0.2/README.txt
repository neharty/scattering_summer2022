################### Running the code ####################
To run the code simply run the .sh named "run.sh". 
This will give the trace for the single observation point
given in the paper. 

For Convergence study, run either conver.sh or conver2.sh.
I suggest running conver2.sh. This is also given at the observation
point from the paper. 


################### Geometry matlab file ################
Much like the other cases, run the geo_to_matlab.sh to get the .mat files
for the geometries.
